# Surefooted website

Static site for [surefootedtech.com](https://surefootedtech.com), served by GitHub Pages. Plain HTML/CSS/JS, no build step.

- `index.html`: the page
- `css/styles.css`: styles
- `js/main.js`: mobile menu and active-link highlighting
- `images/`: logo (SVG) and photos
- `CNAME`: custom domain for GitHub Pages

Preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
